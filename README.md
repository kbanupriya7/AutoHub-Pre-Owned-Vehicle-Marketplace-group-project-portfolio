#  AutoHub – Pre-Owned Vehicle Marketplace

##  About the Project

AutoHub is a pre-owned vehicle marketplace website where users can explore, search, filter and compare used cars and bikes. Users can also view vehicle details, submit enquiries to sellers and list their own vehicles for sale.

This project is developed as a **Week 6 Group Project** to demonstrate our frontend development and JavaScript skills.

##  Features

- **Home Page:** Featured vehicles, latest arrivals, search and category selection.
- **Cars Page:** Browse cars with brand, price, year, fuel type and transmission filters.
- **Bikes Page:** Browse bikes with brand, price, mileage and bike type filters.
- **Vehicle Details:** View vehicle images, specifications, price and seller information.
- **Enquiry Page:** Submit enquiries with form validation.
- **Sell Your Vehicle:** Submit vehicle information with image preview.
- **About & Contact:** Learn about AutoHub, contact information and FAQ accordion.
- **Dark & Light Mode:** Switch between themes on the home page.

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

##  Project Objective

To develop a responsive and user-friendly vehicle marketplace while implementing JavaScript concepts such as DOM manipulation, event handling, array methods, dynamic filtering, sorting, URL parameters, form validation and image preview.

##  Team Project

Developed collaboratively as part of our Full Stack Development Course – Week 6 Group Project.

##  Note

This is a frontend demonstration project. Vehicle listings use sample data, and enquiry and selling forms demonstrate client-side validation without backend integration.
